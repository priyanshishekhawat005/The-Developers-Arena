# Advance CSS & Modern Layouts

A professional, high-performance portfolio template refactored with modern CSS Grid and Flexbox architectures. This project is designed to showcase technical skills and personal projects through a mobile-first, responsive interface that emphasizes clean code and smooth user experiences.

## Project Structure

```text
index.html
css/
  main.css
  layout.css
  animations.css
js/
  theme-switcher.js
screenshots/
```

## Improvements Implemented

- CSS Grid for the main page flow, skills layout, contact layout, and project gallery.
- Flexbox for navigation, hero actions, buttons, card headers, and smaller UI components.
- CSS custom properties in `:root` for colors, typography, spacing, shadows, and transitions.
- Mobile-first responsive design with progressive breakpoints for tablet and desktop screens.
- BEM-inspired class naming for maintainable and scalable styling.
- Smooth hover states, reveal animations, card motion, and a reduced-motion fallback.
- Advanced selectors including `:hover`, `:focus-visible`, `:focus-within`, `:nth-child`, `::before`, and `::after`.
- JavaScript-driven theme switcher, mobile navigation toggle, project accordion, and form validation.
